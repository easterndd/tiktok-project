# v0.0.6-dual 启动归因更新

## 更新内容

- 从当前启动的 WebView URL、入口参数及 SDK 回调收集归因信号；有效 adId 判为已归因，仅 ttoclid、ttclid、click_id 不判为已归因。
- 以 launchId、launchRef 关联启动、归因结果、入口广告决策和埋点，后台支持查询。
- 新客户端声明 launchAttributionVersion=1；未归因或缺失可靠启动记录时跳过入口强弹。旧客户端未声明此协议时保留原入口策略。
- Android 保持双广告位，iOS 保持单广告位；不新增 IP 自动豁免。
- 修复合并后的分集替换及送审清单兼容代码，补充独立的 REPLACEMENT 枚举迁移。

2. 四个 schema 增量创建入口观测、客户端诊断、启动归因及决策表；迁移前备份 schema、迁移记录与入口策略。禁止整体覆盖旧库或执行 seed。
