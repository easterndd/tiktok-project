# 2026-10-30 本地更新与 GitHub 提交记录

## 后端 API 与性能

- 启动链路对并发的匿名会话、入口会话和广告完成请求合并相同在途操作；入口策略短时缓存并在管理后台修改后失效。
- 首页公开数据增加短时响应缓存，个人观看进度单独短时缓存；数据库计时按实际查询记录。响应性能日志对重复慢请求与错误按路由采样，保留被抑制数量。
- 共享 IP 访问按小程序、用户、IP 和时间窗口聚合；使用数据库唯一键保证幂等，控制写入队列并发与长度，缓存近期已完成记录，减少重复写入。IP 豁免查询增加短时缓存，管理员修改后失效。
- 客户端广告失败和低价值播放质量事件默认不持久化，保留兼容响应；可通过 `PERSIST_CLIENT_AD_DIAGNOSTICS` 临时开启广告失败诊断。入口广告 `SHOWN` 计数继续在服务端确认，剧集解锁的奖励校验仍由服务端执行。
- 增加 `/auth/launch-context` 的本地入口广告资格响应，保留策略、归因、用户和 IP 豁免检查；该功能只面向配置了双入口广告位的指定小程序。管理后台统计缓存时长延长到 60 秒。
- 增加 BloomReel 的独立小程序和组织配置、环境变量示例与后台选择入口；BloomReel 小程序目前仅是脚手架，尚无正式广告策略和可发布 Mini 包。

## 小程序前端与构建

- 入口会话、广告展示和入口流程对同一在途操作做合并；减少仅用于诊断的 `REQUESTED` 上报，`SHOWN` 模式不再上报不完整关闭事件。
- StoryFlicks、DramaBlaze、CineReels、DramaHit、TaleTV 增加本地双入口激励广告位配置、轮换与有限备用位尝试；发布检查验证广告位进入构建产物。五个包的正式构建脚本统一使用共享发布脚本。
- StoryFlicks 本地调试增加 API 开发代理，避免调试页跨域；页面初始化 Mini SDK 时防止重复初始化。剧集切换插屏广告位示例补充到环境模板。
- BloomReel 增加独立项目骨架与锁文件记录；尚不能作为正式小程序发布。

## 管理后台与运维

- 管理后台增加 BloomReel 及其组织入口，生产 Docker 构建参数支持对应 API 地址。
- 自托管 API 健康检查改为 `/live`；`/ready` 仍用于就绪检查和外部监控。此变更不代表高负载下的 API 就绪性能已恢复。
- CPU 与遥测写入优化过程见 [20261029-cpu-telemetry-optimization.md](20261029-cpu-telemetry-optimization.md)；StoryFlicks 的本地扫码结果见 [20261029-storyflicks-local-acceptance.md](20261029-storyflicks-local-acceptance.md)。
