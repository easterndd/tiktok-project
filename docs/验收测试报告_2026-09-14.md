# QuicK ReeLS 开发验收报告

**日期：** 2026-09-14
**范围：** 实施文档中的本地可自动化验收项，以及地区可见性发布门禁。

## 本次完成

- 增加服务端地区可见性门禁。专辑的 `regions` 为允许国家/地区列表；未设置表示全球可见。受限内容在国家不匹配或无法获得可信地区时不会被返回。
- 门禁覆盖首页、专辑目录/详情/选集、搜索及兜底推荐、解锁、播放、观看进度、个人观看记录/收藏、互动和播放质量事件。
- 增加 `TRUST_GEO_COUNTRY_HEADER`。只有受信任反向代理覆盖写入 `X-Geo-Country` 后才允许打开；默认关闭。Nginx 模板默认清空客户端提交的该 Header，防止伪造。
- 添加 API 回归用例：非匹配地区不能从首页、目录、搜索、详情或选集接口获得受限内容。
- 点赞与收藏在匿名状态会先触发 TikTok 登录；语言可匿名切换并保存在本地，需身份的播放偏好在登录前禁用，避免无意义的 401 请求。

## 尚不能标记为生产验收通过的外部门禁

以下项目依赖 TikTok Developer Portal、BytePlus 凭证或真机，不能由本地代码替代或伪造：

- 当前 CLI 版本使用 `ttdx minis debug`/`ttdx minis build`；本地 Sandbox/输出检查已通过。仍需在 Portal 上传 ZIP 做 Preview 扫码。
- 当前 App 的官方播放器资格与 Player Reference 参数确认；使用已审核并 Listed 的真实内容测试首帧、连续播放和故障降级。
- IAA 合同/Organization 审批，以及 Rewarded 和 Interstitial Placement 的 Active 状态；真实广告完整观看、中断和加载失败测试。
- HTTPS 域名、Trusted domains、Service domains、地区/主体（包括美国适用项）和 BytePlus 绑定。
- 具备 PostgreSQL 与真实凭证后，执行迁移、seed、上传 Worker 以及后台内容发布闭环测试。

## 部署注意

启用地区定向前，必须让 CDN 或 GeoIP 反向代理移除客户端传入的 `X-Geo-Country`，再写入自身解析的两位 ISO 国家码，并将 API 环境变量 `TRUST_GEO_COUNTRY_HEADER=true`。未完成该配置时保持默认 `false`，受限内容会安全隐藏。
