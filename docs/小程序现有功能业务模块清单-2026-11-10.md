# 小程序现有功能与业务模块清单

> 盘点日期：2026-11-10。本文按当前工作区源码、项目接口/全链路文档和本次只读线上路由核对整理。它区分“代码实现”“后台界面可操作”和“线上路由已核实”，不把代码注册或数据库中有配置等同于 TikTok Portal 已发布或已有真实用户流量。

## 1. 当前运行范围

- 小程序用户端由 `apps/mini-web` 提供共用页面与业务逻辑，各品牌目录单独注入品牌、API 地址、TikTok App 配置和 release 配置后构建各自代码包。
- 本次线上路由核对确认，DramaFlicks、HeartReel、SweetReel、LuxeReel 的核心 API 路由指向 `api-v006-dual:3000` 对应的 v0.0.6 dual API 容器。
- DramaFlicks、HeartReel、ZenClip、SweetReel、LuxeReel 的 analytics 路径另由 `api-five-analytics-candidate` 处理。ZenClip 出现在这组诊断/统计路由中，不等于其核心业务 API 也在上述 dual API 上。
- 旧候选 API 容器仍运行、其他品牌也存在默认或历史路由组。运行中的容器、代码登记的小程序 key、TikTok Portal 已发布的小程序、实际产生流量的小程序是不同口径；本次资料不能证明所有登记品牌都在运营。
- 仓库按品牌 key、独立数据库上下文、管理后台品牌切换设计多小程序。生产环境是否启用某一品牌，仍要逐项核对代理路由、数据库、环境变量、代码包和 Portal 状态。

## 2. 用户端 Mini 前端

### 2.1 启动、身份和应用状态

- 载入品牌 Mini 包，初始化 TikTok Minis SDK，建立 React 页面、路由、请求缓存和全局运行诊断。
- 默认建立匿名业务观众会话，保存访客标识和本次 WebView 会话标识；用户 JWT 与管理员 JWT 分离，并按小程序隔离。
- 支持 TikTok OAuth 会话接口，可将 TikTok 授权身份与匿名观众关联。是否出现登录入口取决于当前页面/品牌配置；API 支持不代表用户界面一定提供主动登录入口。
- 读取启动参数、入口来源、scene 和 release 信息，为活动深链、广告门禁及分析归因提供上下文。
- 支持品牌级语言设置与本地偏好；当前代码语言包括英语、葡萄牙语、法语、印尼语、日语、西班牙语、韩语和泰语。

### 2.2 页面与内容发现

| 页面/路由 | 当前业务功能 | 备注 |
| --- | --- | --- |
| `/` 首页 | 热门/上新频道、焦点轮播、剧目海报列表、可选预览视频、继续观看、首页内搜索、加载/失败重试、公开首页缓存 | 首页数据由 API 提供；个性化继续观看需要用户会话。 |
| `/search` | 跳转至首页搜索状态，按关键词查询剧目并展示空结果/回退推荐 | `SearchPage` 组件及分类 API 存在，但当前路由表没有直接挂载该页；不能把独立分类页当作当前可见页面。 |
| `/album/:albumId` 剧目详情 | 查看剧目资料和分集，收藏，选择可播放分集；锁定分集进入激励广告解锁流程 | 内容是否可见、分集是否可播由服务端再次判断。 |
| `/watch/:albumId[/episodeId]` 播放页 | 播放指定分集、集列表/切集、锁集解锁、播放失败重试、相邻集预取和自动衔接 | 由官方 VePlayer 播放 TikTok/BytePlus 关联的媒资。 |
| `/profile` 个人页 | 观看历史、语言偏好、隐私政策和服务条款入口 | 用户资料及观看记录属于当前品牌用户空间。 |
| `/favorites` 收藏页 | 查看已收藏剧目 | API 支持当前用户最近收藏列表。 |
| `/privacy`、`/terms` | 展示品牌对应的隐私政策和服务条款 | 页面内容本地构建，不依赖内容 API。 |
| `/debug` 调试页 | 查看客户端运行、广告与播放器诊断信息 | 仅在 `debugPanelAvailable()` 条件成立时注册，不是普通用户必然可见的产品页。 |

### 2.3 播放、权限和用户互动

- 首页/详情/播放接口按品牌库读取已上线剧目与分集，并可按地区和平台发布状态过滤。
- 免费集或已经解锁的分集可直接请求播放参数；锁定集需要先完成对应广告会话。
- 每次取得播放参数时，API 再验证剧目/分集发布状态、地区限制、免费规则、用户解锁记录以及 TikTok 剧目 ID、分集 ID和 BytePlus VID 等播放资料。
- Mini 使用 TikTok `VePlayer` 初始化播放器，接收播放凭证和续播位置，监听 READY、首帧、播放、暂停、错误、结束等事件；本地开发模式可使用 HTML video。
- 播放中定期、暂停或离开时保存进度；历史/继续观看使用该进度恢复。播放事件会上报启动耗时、首帧、卡顿/等待、网络、清晰度、错误及结束信息。
- API 支持点赞、收藏、分享、搜索记录和剧集完播记录。当前可确认详情页使用收藏；点赞/分享是后端能力，是否有当前用户端入口需按实际页面确认。

### 2.4 广告业务

- **进入广告门禁**：按构建 `releaseId` 读取入口广告策略，可配置插屏或激励广告、展示次数、按“展示”或“完成”计数、不可用时允许进入或阻止进入。每次启动有独立会话和 TTL。
- **锁集激励广告**：为特定分集创建/恢复奖励会话；每次广告展示、关闭和完成都带事件 ID、广告位和次数序号回传。服务端校验证据后才累加次数并创建解锁记录，未完成广告不会满足“完成后计数”的规则。
- **剧集插屏**：可配置延迟、播放集数/切换间隔、单会话上限及与激励广告的冷却关系；与锁集解锁和入口门禁是不同策略。
- **退出挽留广告**：有独立启停与次数策略，不由入口广告开关单独决定。
- **多广告位/系统策略**：release 为 `v006-dual` 时，当前项目代码/后台说明采用 Android 主备位并行准备和轮换、iOS 主广告位单路的策略；实际可用广告位仍取决于对应品牌、发布包、Portal 审批及 SDK 运行结果。旧版 release 可使用后台数据库中的广告位配对和平台加载模式。
- 前端包含广告对象缓存、平台识别、placement 选择、失败分类、超时、重试、展示/关闭确认和诊断埋点；创建广告对象或调用 show 不代表广告一定有填充或成功展示。

## 3. 后端 API 与服务

API 为 Fastify 服务，通过主包 `/api/v1` 或品牌前缀 `/api/{miniAppKey}/v1` 提供能力；用户接口使用用户 JWT，后台接口使用独立管理员 JWT。每个品牌业务数据使用单独数据库连接上下文；配置共享库时，共享媒资和授权状态进入共享数据域。

| API 业务域 | 主要职责 |
| --- | --- |
| 健康检查与静态资源 | `/live` 进程存活、`/ready`/`/health` 数据库就绪、封面资源读取。 |
| 身份与会话 | 匿名观众会话、TikTok OAuth code 交换、匿名观众绑定、启动参数与入口归因。 |
| 首页与发现 | 首页区块/剧目 feed、继续观看、剧目列表与详情、分类、搜索及回退推荐。 |
| 剧目与播放 | 分集列表、发布/地区/访问规则、播放参数和 BytePlus 可选播放凭证、播放授权检查。 |
| 用户资料与进度 | 用户资料、偏好、历史、收藏、观看进度与续播。 |
| 用户互动 | 点赞、收藏、分享、搜索事件和完播事件。 |
| 广告与权益 | 广告事件证据、入口广告策略/会话/完成回执、锁集激励 session/unlock、插屏和退出挽留配置。 |
| 页面配置 | UI 组件开关、版本/ETag 和首页区块等读取/管理 API。 |
| 统计与诊断 | 播放质量事件、客户端 runtime error、广告/播放器原始诊断 trace、分析汇总。错误上报会做限流和脱敏，诊断不作为广告解锁凭据。 |
| 管理接口 | 管理员认证与权限、内容/媒资/平台任务、广告策略、入口链接、观众分析、健康状态及审计等后台 API。 |

### 3.1 内容和平台服务链路

1. 后台提交剧目、分集、免费/广告访问规则、封面和视频资料。
2. API 保存业务元数据，视频进入上传任务，由 worker 上传或恢复 BytePlus VOD 上传，取得 VID、时长等信息。
3. API/worker 将封面、视频和版本同步到 TikTok Short Drama 平台。
4. 有权限的管理员提交审核、对账、设置线上版本并执行上架/下架。
5. 只有满足本地发布状态和平台授权等条件的内容才由公开 API 返回；“已入队”不代表平台已审核或发布成功。

### 3.2 主要数据库业务数据

- 内容：剧目、分集、封面、翻译、分类、访问配置、平台版本/审核/上下架状态。
- 观众：User、AppSession、偏好、观看进度、收藏、点赞、分享、搜索及完播活动。
- 广告：广告事件、奖励会话/奖励记录、分集解锁、入口策略/会话/完成记录、广告位配对。
- 播放与分析：播放会话、播放质量事件、客户端诊断、日汇总、概览快照和广告收入导入记录。
- 运营与安全：上传任务、TikTok 平台同步任务、管理员、操作审计。
- 跨品牌共享：共享媒资、共享 TikTok 剧目/分集映射、品牌授权及共享平台操作任务。

PostgreSQL 保存内容、状态和业务记录；视频文件由 BytePlus VOD 持有。TikTok/BytePlus 密钥留在 API/worker 服务端，不进入 Mini 构建包。

## 4. 运营后台

后台是独立的 `apps/admin-web` 网站，不进入用户 Mini 包。运营先选品牌，再使用该品牌的管理员凭据和 API 前缀；不同品牌的管理员角色、数据库、草稿/模板空间相互区分。导航会按角色和权限隐藏部分入口，服务端仍会二次校验权限。

| 后台导航 | 当前可操作的业务 |
| --- | --- |
| 概览 | 查看剧目数、分集数、观众数、互动/解锁汇总、运行健康、近期上传/任务状态。 |
| 内容创建 | 创建整部剧或向已有剧追加分集；填写剧名/描述/年份/类型/标签；设置免费集和激励广告解锁；批量选择视频/封面、绑定已有 VID；本地草稿/模板、上传进度、失败任务重试/对账。 |
| 剧集与解锁 | 编辑剧目、分集、封面/翻译及访问规则；查看上传和平台任务；同步媒资/版本、提交审核、对账、设线上版本、上架/下架；查看 TikTok 返回的审核失败原因；为同组织其他品牌授权已审核剧目播放并核对分集映射。 |
| 进入广告 | 按 release 配置入口广告启停、插屏/激励模式、广告位、展示次数、计数规则和不可用回退；可查看/编辑旧版主备位配对及 iOS/Android 加载模式。`v006-dual` 的新包主备位由前端清单控制，后台数据库配对不是该 release 的来源。 |
| TikTok 入口 | 配置和核验 Preview/Production Minis 基础入口；为符合条件的上线免费分集生成活动深链；查看最近观测到的前端 release。 |
| 观众数据 | 按日期与时区查看活跃/新增观众、观看会话、完播、互动和国家/地区统计。 |
| 播放质量 | 查看播放器事件、首帧、平均启动耗时、错误率、清晰度/网络分布和最近错误；指定品牌支持时可查看 v0.0.6 播放诊断。 |
| 账号安全 | 查看当前管理员、角色和最近登录，修改本人密码；更新后当前令牌失效。 |

广告页另含 OWNER 专属观众入口广告豁免、共享 IP 查看/豁免和部分品牌的 v0.0.6 广告/客户端 trace 诊断。具体内容依品牌和权限显示。

## 5. 已实现但不等于后台已有操作页面的能力

以下接口/数据模型在项目中存在，但不能一概当作当前后台主导航中有完整配置 UI：

- UI 组件版本、首页区块/区块项目、分类和若干页面运营配置 API 已存在；后台主导航没有完整的 CMS 配置器。
- 管理员列表新增/改角色/停用、审计日志读取有 API，但当前主导航没有独立管理页。
- 收入数据读取/导入接口存在，但当前主导航没有收入导入工作区。
- 独立分类搜索页组件/API 存在，但当前路由将 `/search` 重定向到首页搜索状态。
- 点赞和分享记录 API 存在；应以当前 Mini 页面是否有入口为准，不能仅凭 API 认定用户能操作。
- 某些跨品牌共享/诊断接口仅在 OWNER、指定品牌或带目标品牌令牌时可用。

旧的部分多品牌发布/手工授权接口已标记停用并返回 `410 FEATURE_RETIRED`；当前授权工作流应使用“已审核剧目授权播放”的共享播放接口。

## 6. 主要用户与运营闭环

```text
观众打开 Mini
  -> SDK 初始化/匿名会话/入口归因
  -> 按 release 策略完成入口广告（若启用）
  -> 浏览首页、搜索、剧目详情
  -> 免费集直接播放，锁集完成激励广告并获得服务端解锁
  -> API 复核播放权限并签发播放参数
  -> VePlayer 播放、记录进度/质量/错误，用户继续观看或收藏

运营创建剧目
  -> 上传视频/封面并绑定 BytePlus VID
  -> 同步 TikTok 媒资与版本
  -> 审核、对账、设置线上版本、上架
  -> 用户端公开内容读取
```

## 7. 当前边界与需要单独确认的事项

- **广告运行状态**：Android 双广告位与 iOS 单广告位是项目对 `v006-dual` release 的现行实现策略。每个品牌的主/备 ID、Portal 核准状态、SDK 是否提供 load 能力、系统版本/地区填充率和线上实际成功率需要按品牌及真机数据验证，不能从代码静态清单推断。
- **线上品牌范围**：本次只读核对确认上述四个品牌的核心 API 指向 v0.0.6 dual；analytics 另确认五个品牌路由。其余品牌容器或路由仍需结合当前代理配置、数据库环境、Mini 包和 TikTok Portal 状态逐一验收。
- **多小程序 key 数量**：代码中的品牌 key 是可配置/可挂载范围，不是活跃用户数或已上线数。独立数据库环境变量缺失的品牌不会因此自动成为运行中的正式服务。
- **播放器/广告诊断**：前端事件依赖小程序实际运行并成功上报；后端记录可能有延迟、丢弃/脱敏或按品牌开关限制。后台面板显示空数据不等于功能未实现，也不能单凭聚合事件断定 SDK 失败原因。
- **内容平台状态**：本地数据库的 `ONLINE`、TikTok 审核通过、线上版本、平台上架是不同状态；后台任务入队成功不是最终发布成功。
- **本文件范围**：这是当前实现的功能目录，不是对每个品牌 Portal 发布、广告位审核、用户数据量或真机验收的证明。
