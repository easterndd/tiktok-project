# QuicK ReeLS 与 xu03

## Architecture

- One API process and one upload worker process can serve both mini apps.
- Original app endpoints remain under `/api/v1`.
- `xu03` endpoints use `/api/xu03/v1`.
- The two contexts use separate PostgreSQL schemas or databases, so albums, episodes, users, ad policies, analytics, and TikTok sync IDs are isolated.
- BytePlus VOD `Account ID`, `Space`, AK, and SK can be shared when both TikTok apps are bound to that BytePlus account. Every drama still uses one BytePlus account and one Space.

## Server environment

```env
DATABASE_URL=postgresql://.../quickreels?schema=public
XU03_DATABASE_URL=postgresql://.../quickreels?schema=xu03
TIKTOK_CLIENT_KEY=original_app_client_key
TIKTOK_CLIENT_SECRET=original_app_client_secret
XU03_TIKTOK_CLIENT_KEY=xu03_client_key
XU03_TIKTOK_CLIENT_SECRET=xu03_client_secret
BYTEPLUS_ACCOUNT_ID=shared_byteplus_account_id
BYTEPLUS_SPACE_NAME=shared_vod_space
BYTEPLUS_ACCESS_KEY=shared_byteplus_ak
BYTEPLUS_SECRET_KEY=shared_byteplus_sk
```

Run the Prisma migration against both schemas before enabling `xu03`. Seed or create the `xu03` administrator in that schema. The server-side secrets must stay out of both Mini bundles and the admin frontend.

For a PostgreSQL database shared by both apps, create the `xu03` schema and grant the API database user access. Then run `prisma migrate deploy` with `DATABASE_URL` pointing at `?schema=xu03`. Do not run the demo content seed in production. Run the administrator bootstrap script against the `xu03` URL after building the API.

## Admin workflow

Open the same admin URL and select `QuicK ReeLS` or `xu03` from the app selector. The selected context uses its own endpoint, admin token, drafts, templates, content, ad policy, and platform status.

## TikTok setup

1. Create the `xu03` app and put its numeric App ID in `apps/xu03/minis.config.json`.
2. Build `xu03` with its own public Client Key and API URL.
3. In `xu03` Industry solutions, bind the shared BytePlus Account ID using a valid AK/SK and confirm `Connected`.
4. Register and publish `xu03` content separately. Do not copy old app `album_id` or `episode_id` values.
5. Review the legal pages for the new application's actual operator before submitting it for TikTok review.
