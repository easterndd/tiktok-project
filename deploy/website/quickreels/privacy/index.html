2 Information We Collect

2.1 TikTok login information

When you choose to sign in, we process the temporary authorization code supplied by TikTok Minis and the TikTok OpenID returned by TikTok. We use the OpenID to recognize your Service account. Under the current implementation, TikTok access and refresh tokens are used only for the authentication exchange and are not stored as persistent user account records.

2.2 Service activity

We store information needed to operate the Service, including viewing progress, completed episodes, content unlock records, favorites, likes, locale and playback preferences, and service interactions.

2.3 Advertising and diagnostics

When advertising features are available, we may process rewarded-ad request, display, completion, early-close, and error events to determine access to an episode and to diagnose the Service. We may also receive technical information such as IP address, request headers, device or runtime information, language, error reports, and security logs.

2.4 Information you send us

If you contact us, we process the contact details and message content that you provide so that we can respond.
