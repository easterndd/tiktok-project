# SweetReel

This Mini shares the UI in `apps/mini-web` and uses the independent `sweetreel` API and PostgreSQL schema. Fill `.env` with the public Client Key and API URL; keep the Client Secret and database URL on the server. Set the real App ID in `minis.config.json` before `pnpm --filter sweetreel build:minis:release`.
